# 🧊 三阶魔方 · 新手还原教程

一个基于 **Python + Three.js** 的三阶魔方网页应用：既能对着 3D 动画学"分层七步法"，也能让程序**自动求解并逐步演示还原**，还支持**录入实物魔方状态**获取还原指导。

## ✨ 功能简介

- **3D 交互魔方**：浏览器内实时渲染，左键拖动旋转视角、滚轮缩放；可用工具栏按钮或键盘 `R U D L F B`（`Shift` = 逆时针）手动转动。
- **打乱 / 复位**：一键随机打乱并播放动画，或恢复到还原态。
- **分层七步法教程**：右侧面板逐步讲解，每一步都给出「🎯 目标 / 🧭 怎么拿 / ✅ 算完成 / 🧩 怎么做」，公式卡上直接写明「👉 什么时候用」，可"单步执行 / 自动播放"，高亮当前转动，跟着做即可。
- **🤖 自动还原**：调用后端 Kociemba 两阶段算法求出接近最优的还原步骤，并在 3D 模型上逐步播放。
- **👣 单步还原**：在自动解法基础上一次只走一步，方便逐手跟做。
- **📥 录入实物魔方**：弹窗内用调色板点/刷录入 6 个面（中心自动填），校验后重建 3D 模型、自动求解，并以悬浮指导栏给出"文字步骤 + 3D 动画 + 单步"的还原指导。
- **📸 摄像头扫描**：网页里一键启动 `cube_scanner.py`（在本机弹出摄像头窗口逐面拍照）。程序会自动找到魔方、对齐摆正每个面，**无需把魔方对准取景框**，绿框保持稳定约半秒即自动采集（也可按空格立即采集）；若上次结果未通过校验（或没采满 6 面），再次打开扫描窗口时会提示按 Y 载入原数据继续修正，并指出哪些面有问题（只需重拍这几个面）、按 N 重新扫描。扫描结束自动导入识别结果，也可手动点「📷 导入扫描」读入命令行扫描的最新结果。采满 6 面保存后会自动清理上一次扫描遗留的 json 与标注图，目录里只保留最新一次结果（未采满就退出时不清理）。

## 🧱 技术栈

| 层 | 技术 |
| --- | --- |
| 前端 | 原生 HTML/CSS/JS + [Three.js](https://threejs.org/) `0.160`（ES Module + importmap） |
| 后端 | Python 标准库 `http.server`（无 Web 框架） |
| 求解引擎 | `cube-solver`（纯 Python + C 加速的 Kociemba 两阶段算法） |

## 📁 目录结构

```
cube/
├── app.py              # 后端：静态页面服务 + 教程/求解 API
├── web/
│   └── index.html      # 前端：3D 魔方、教程、自动还原、实物录入
└── tables/             # cube-solver 使用的剪枝/转移表（自动生成，**不入库**）
```

> `tables/` 中的 `pruning_kociemba.npz` 体积约 1.5 GB，超过 GitHub 单文件上限，已写入 `.gitignore`。克隆仓库后无需手动处理：安装 `cube-solver` 并首次求解时会自动重建这些表（需等待若干秒并占用数 GB 磁盘）。

## 🚀 运行

```powershell
# 1. 安装依赖（求解引擎，可选；不装则"自动还原/录入求解"不可用，其余功能正常）
pip install cube-solver

# 2. 启动（服务就绪后会自动拉起系统浏览器打开教程页面）
python app.py
```

## 🔌 API 一览

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/` `/index.html` | 返回前端页面 |
| GET | `/api/steps` | 分层七步法教程数据 |
| GET | `/api/notation` | 转动符号（R U D L F B）说明 |
| GET | `/api/scan/latest` | 读取 `cube_scans/` 里最新一次 `cube_scanner.py` 扫描结果，校正面朝向并转为录入状态 |
| POST | `/api/scan/start` | 在本机启动 `cube_scanner.py` 摄像头扫描程序（页面「📸 启动摄像头扫描」按钮调用） |
| GET | `/api/scan/status` | 查询扫描进程状态与是否产出了新结果（页面轮询用，扫描结束自动导入） |
| POST | `/api/solve` | 接收魔方状态，返回还原步骤 |

`POST /api/solve` 请求体与响应：

```jsonc
// 请求
{ "repr": "<54 位 facelet 字符串>" }
// 响应
{ "moves": ["R", "U'", "F2"], "solution": "R U' F2", "count": 3 }
```

## 📖 教程怎么读

- **拿法约定**：所有公式按「白色中心朝下当底面、黄色朝上」编写，动手前先把魔方摆成这个拿法（3D 模型默认白色在上，与教程拿法相反）。文中「朝前 / 朝后 / 朝左 / 朝右」一律指**你手里的方向**，不是屏幕上的方向。
- **两种"转"别搞混**：「水平转动整个魔方」= 整个魔方一起左右转 90°，用来找位置；它和「转顶层 `U`」完全不同 —— 做第 5、6、7 步时靠转 `U` 找位置会把已归位的块带走。
- **一步内的多条公式是"选项"不是"顺序"**：按卡片上的「👉 什么时候用」挑当前符合的那一条，做完再重新判断。长公式会按 4~5 步一组分块显示，换行只发生在组之间，便于对齐手顺。
- **正确性**：教程里的每一条公式与判定规则都用面片级魔方模拟器穷举验证过 —— 第 5 步规则覆盖全部 148 个「顶十字已完成」入口局面、第 6+7 步规则覆盖全部 287 个顶层排列局面，均 100% 收敛（角公式最多 4 次、棱公式最多 2 次）；第 1~4 步用逐块位置断言验证。文案因此只写实测成立的现象，不做"大概如此"的推测。

## 🎨 配色与状态约定

- 配色：**上白(W) · 下黄(Y) · 前绿(G) · 后蓝(B) · 右红(R) · 左橙(O)**（中心块决定各面颜色）。
- facelet 字符串：长度 54，字符集 `WGRYBO`，顺序为 **U L F R B D**，每面按行优先 9 格。前端与后端 `cube-solver` 完全一致。

> 说明：录入实物时需填满 6 个面才能**唯一确定**状态。经数学验证，只录 5 面存在无法消除的歧义（约 9% 的状态会有多个合法底面），故为保证还原指导正确，采用 6 面录入。

## ⚠️ 备注

- 未安装 `cube-solver` 时后端会自动降级，仍可浏览教程与手动练习，仅"求解"相关功能不可用。
- `cube-solver` 在部分 Windows 环境无预编译包，需要时按提示安装对应 wheel。
